 **GeoFS Multi‑Aircraft Overhead Panel Addon**

This addon adds fully interactive, realistic overhead panels to GeoFS for a growing list of aircraft. Every panel is custom‑built to match the real cockpit layout, including authentic switch types, lighting logic, electrical systems, hydraulics, bleed air, anti‑ice, and engine start controls.  

The UI is modular, draggable, and designed for realism while still being easy to use in a browser. Each aircraft loads its own unique overhead with accurate colors, labels, and system grouping
**Aircraft**
- Airbus A220 / A320 / A330 / A340 / A350 / A380  
- Boeing 737 / 747 / 757 / 767 / 777 / 787  
- MD‑11  
- L‑1011 TriStar  
- CRJ‑200 / CRJ‑700  
- Embraer E190  
- ATR‑72  
- Dash‑8 Q400  

### **Features**
- Realistic pushbuttons, rocker switches, and rotary engine start knobs  
- Authentic Airbus, Boeing, McDonnell Douglas, and Lockheed color themes  
- System groups: Electrical, Fuel, Hydraulics, Bleed Air, Packs, Anti‑Ice, Lights, Engine Start  
- Pop‑up feedback for every switch  
- Draggable, collapsible overhead panel  
- Accurate 3‑engine support for MD‑11 and L‑1011  
- Expandable design for future aircraft  

### **Why this addon is unique**
Unlike simple light toggles, this addon recreates the *actual overhead logic* of each aircraft family. Airbus uses pushbuttons, Boeing uses rockers, the MD‑11 has triple‑redundant systems, and the L‑1011 has its iconic Lockheed layout. Everything is built to feel like a real cockpit.
